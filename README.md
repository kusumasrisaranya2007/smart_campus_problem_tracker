# Smart Campus Tracker (SCT)

## Description
**Smart Campus Tracker** is a premium, retro-futurist campus management system built with a focus on high-efficiency data monitoring and distinctive "Glitch Art" aesthetics. It allows educational institutions to manage students, attendance, complaints, transport, and placements through a centralized, zero-latency interface.

## Tech Stack
- **HTML5**: Semantic structure.
- **CSS3**: Custom glitch animations, scanline effects, glassmorphism, and responsive grid layouts.
- **JavaScript (Vanilla)**: Core logic, LocalStorage persistence, Canvas API for data visualization, and DOM manipulation.

## Key Features
- **Integrated Dashboard**: Real-time monitoring of campus vitals with animated data cards and activity charts.
- **Student Matrix**: Full CRUD operations for student records with photo URL integration.
- **Biometric-Simulated Attendance**: Daily attendance tracking with percentage reporting and CSV export.
- **Priority Complaint System**: categorize and track campus issues from "Hostel" to "WiFi" with priority levels.
- **Digital Notice Board**: Instant publication of campus news with urgency flags.
- **Event Chronos**: Lifecycle management for campus events with real-time countdown timers.
- **Logistics Hub (Transport)**: Route management, driver tracking, and seat availability monitoring.
- **Placement Terminal**: Track upcoming corporate drives and eligibility criteria.
- **System Settings**: Customizable UI hue control and system-wide data backup (JSON).

## How to Run
1. Open `index.html` in any modern web browser.
2. Click **Initialize System** to launch the OS.
3. All data is persisted in your browser's LocalStorage.
